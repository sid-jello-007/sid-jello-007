#### 🧭 How I work

- **Problem first, model second.** Start from the handoff that hurts, not the technology.
- **Evals before agents.** Agree what "good" looks like, then build to it.
- **Guardrails are product features.** Show users and risk partners when they kick in.
- **Measure flow, not activity.** DORA and SPACE over lines of code generated.
